# Some Random Tower Defense Game

> **Work in progress:** This project is still in the planning and development stage. It is not yet playable or ready for release.

A cool-looking, humorous fantasy-parody tower-defense game planned as a mobile-friendly, installable browser PWA. The goal is to combine strategic towers and ridiculous enemies with branching campaign progression, optional challenges, and mastery goals that reward different ways to play.

Planned save support will include local progress with optional synchronization through a Railway-hosted service. These features are goals for the project and should not be considered implemented yet.
